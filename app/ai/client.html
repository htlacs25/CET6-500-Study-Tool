第一次使用？点这里 · 手动改页面无需 API Key

先选你想做的事。下方引导按钮只带你到对应位置，不会发送问题、保存密钥或应用修改。

1. 先试手动改页面

不需要 API Key，也不调用 AI。

  1. 进入“改页面与功能”，找到“自己动手改 · 免费”。
  2. 选配色、字号或单词展示，点“生成修改预览”。
  3. 点“试用修改后的页面”，满意后点“确认应用到我的页面”。

先试：把“单词展示”选为“列表”。

2. 让 AI 辅导学习

需要你自己的 API Key。

  1. 展开“连接设置”，填入 API Key 和可用的模型名称，再点“保存连接设置”。
  2. 在“学习助教”输入问题，点“发送给 AI”。
  3. 如有安排建议，先看“待确认的修改”，决定是否点“确认应用”。

可以问：请用简单例句讲讲 which 和 that 的区别。

3. 让 AI 帮你改页面

先完成连接设置，再描述想要的效果。

  1. 进入“改页面与功能”，输入要求，点“让 AI 生成修改方案”。
  2. 查看方案，点“试用修改后的页面”。
  3. 满意后点“确认应用到我的页面”；不满意可点“这次不改”。
  4. 已应用后，可在“我的页面修改记录与撤回”点“撤回这次页面修改”。

可以说：把听力放在最前面，加一个 15 分钟计时器。

手动修改也可以在“我的页面修改记录与撤回”撤回。页面编辑支持现有布局和组件；新增组件类型、联网服务等需要另外开发。

密钥只填在“连接设置”的 API Key 框，不要写进聊天。还没有密钥时，可以先使用手动编辑。
