# CET6 500 分学习工具

一个本地运行的大学英语六级学习网页工具，目标是按日期提供词汇、听力、语法、阅读、长难句和翻译练习。

## 主要功能

- 每日课程自动切换，并显示前后 3 天内容
- 单词音标、朗读、听音默写和中英双向默写
- 错词与首次正确率在当前浏览器本地保存
- 可调语速的合成听力、听写和理解题
- 阅读、语法、长难句与翻译练习，提交后查看答案和解析
- 按间隔复习规则安排新词、旧词和错词

## Windows 快速启动

双击项目根目录的 `启动学习工具.cmd`，浏览器打开后即可使用。停止服务时双击 `停止学习工具.cmd`。

也可以进入 `app` 目录后运行：

```powershell
npm install
npm run dev
```

## 独立网页

根目录的 `六级学习工具.html` 可作为本地入口。每日课程内容位于 `app/content/daily-lessons.json`，同步脚本位于 `app/scripts/`。

## 数据说明

学习成绩、错题和草稿保存在使用者当前浏览器的本地存储中，不包含在本仓库，也不会随 Git 提交上传。

课程中的基础恢复材料为原创分级模拟；浏览器朗读为合成语音，不冒充历年真题录音。
