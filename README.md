# CET4 550 分学习工具

一个本地运行的大学英语四级学习网页工具，目标是循序渐进冲刺 2026 年 12 月四级 550 分。核心功能是按中国日期每天自动安排并更新词汇、听力、语法、阅读、泛读口语、长难句和翻译练习。

## 主要功能

- 按中国日期每天自动安排并切换新课程，同时显示前后 3 天内容；每一天在首屏直接显示独立主题、阅读和听力标题
- 正常日学习 12 个新/激活词和 18 个复习词，全部 30 词进入乱序听音/中英双向默写；周测日不加新词，默写全部 20 个复习词。默写区下方可直接重默当日错词，独立保存重练结果，不覆盖首次成绩
- 单词音标、朗读、听音默写和中英双向默写
- 每页顶部“查词”或 Alt + K 打开离线搜索；选中一个英文词再按快捷键可直接查。文章点词后也可点“查看词族 / 词形”。搜索区占用独立布局空间，不覆盖文章或答题框，收起后恢复阅读宽度
- 搜索显示中文词义、词性、音标、相关名词/动词/形容词/副词，以及已收录动词的过去式、过去分词、现在分词和第三人称单数。保留多义词与不规则变化说明；查词不计错、不自动加入背诵，不修改成绩或草稿
- 错词与首次正确率在当前浏览器本地保存
- 可调语速且可随时暂停、继续、停止的合成听力，配有全文分段听写和理解题
- 每天额外一篇 180—240 词的四级难度泛读（公版名著原创改写或原创报刊风格短文），支持整篇朗读、逐词查义、理解题、影子跟读和 30—60 秒复述
- 阅读文章与听力原文支持逐词点选中文释义；只有手动确认的词才加入后续背诵
- 阅读、语法、长难句与翻译练习，提交后查看答案和解析
- 按间隔复习规则安排新词、旧词和错词
- 自主加入的文章词按间隔进入每日固定主动回忆名额，不增加每天题量，并可随时移出
- 错词按 D1/D3/D7/D14 到期复习并轮换顺序，不会把同一个词无条件固定在每天第一位

## Windows 快速启动

### 离线查词数据

`app/content/word-search.json` 是独立于课程和学习记录的词典显示层，包含约 2.9 万个常用词及词形。词义与词形来自 ECDICT，词族由常用词族整理和 WordNet 3.0 的词汇派生关系构建。只沿明确的词义节点最多两步检索，不用同义词、上下位词或后缀猜词。词典可能有缺漏，相关词不保证能在原句直接替换；“未收录”不代表不存在。

原始词典只保存在被忽略的 `runtime-temp`，不会上传；许可证随词典 JSON 和独立 HTML 一起分发。重新生成时，将官方 ECDICT 的 `ecdict.csv` 与解压后的 WordNet 3.0 目录作为参数：

```powershell
node app/scripts/build-word-search-data.mjs <ecdict.csv路径> <WordNet-3.0目录>
node app/scripts/sync-daily-content.mjs
```

### 启动

双击项目根目录的 `启动学习工具.cmd`，浏览器打开后即可使用。停止服务时双击 `停止学习工具.cmd`。

也可以进入 `app` 目录后运行：

```powershell
npm install
npm run dev
```

## 独立网页

根目录的 `六级学习工具.html` 可作为本地入口。每日课程内容位于 `app/content/daily-lessons.json`，同步脚本位于 `app/scripts/`。建议固定使用同一种入口；`file://` 与 `localhost` 的浏览器记录彼此独立，但课程文件现在会同步为同一版本。

当前已准备独立课程至 2026-09-30。若后续某天课程尚未生成，网页会明确显示“课程尚未生成或同步”，不会循环旧题冒充新课。

## 数据说明

学习成绩、错题和草稿保存在使用者当前浏览器的本地存储中，不包含在本仓库，也不会随 Git 提交上传。

课程中的基础恢复材料、报刊风格短文均为原创分级模拟；名著材料是基于公版作品重新编写的四级难度短文。浏览器朗读为合成语音，不冒充历年真题录音。

文章点词释义使用离线 [ECDICT](https://github.com/skywind3000/ECDICT) 数据，采用 MIT 许可证；完整声明见 `THIRD_PARTY_NOTICES.md`。词义只在点击后显示，查看本身不会自动加入复习。

## 每日更新与 GitHub 同步

每日自动任务先检查前后 3 天课程是否齐全，并核对课程日期、整套题目指纹、阅读、听力和泛读正文是否重复、听写是否覆盖全文、文章词是否都有本地释义，再同步根目录、开发入口和已有生产构建中的网页。当天课程完整但未来课程尚待生成时，本地入口仍可打开今天并禁用缺课日期；当天缺课或课程结构异常才阻止启动。检查通过后，`每日同步到GitHub.ps1` 只提交课程数据及生成网页等指定文件，并核对本地与远程 `main` 的提交哈希。

在 Windows 上，若没有显式 Git 或环境变量代理配置，同步脚本会沿用当前账户已启用的静态系统代理，解决浏览器能访问 GitHub 而 Git 直连超时的情况。代理只用于本次命令，不修改全局 Git 设置；PAC 自动配置不在此读取范围内。代理未运行或网络中断时，本地提交仍保留，可在恢复后重试。

双击 `Finish-Sync-Update.cmd` 可把已列入白名单的功能源码和每日网页一起同步。启动器与每日脚本均使用 `sync-runtime.ps1` 定位完整 Git，优先使用本地 `runtime/PortableGit-2.55.0.5/cmd/git.exe`，再检查已安装 Git；不依赖双击窗口的 PATH，也不会修改全局环境变量。只有带 HTTPS 上传组件的 Git 才能通过检查。Node.js 不在 PATH 时会检查标准安装位置。失败时窗口保留错误，诊断日志存于被 Git 忽略的 `logs/` 目录。

便携 Git 只保存在这台电脑，不随仓库上传。在另一台电脑使用时，可安装 [Git for Windows](https://git-scm.com/install/windows)，或将官方便携版解压到上述 `runtime/` 目录；仍需该电脑自己的 GitHub 授权。该目录及下载包、日志、备份均不包含在同步白名单内。同步不使用强制推送，也不自动合并远程冲突。

浏览器若保存过错日或旧版课程快照，网页会自动隔离错误快照、显示所选日期的正确课程，并把旧首次成绩、错题和草稿压缩归档；新版题目使用独立作答键，不混入旧分数。固定课程素材与个性化复习词分别识别，新增错词不会误触发整课替换。课程草稿绑定到具体课程版本，避免跨天套用。

脚本不会使用 `git add .`，不会上传浏览器中的成绩、错题或草稿，也不会把缓存、日志和备份加入仓库。电脑或 Codex 未运行、目录无写权限、网络中断或 GitHub 授权失效时，当天推送可能延后；本地学习网页和已有记录不会因此被删除。

只检查、不提交：

```powershell
.\每日同步到GitHub.ps1 2026-09-02 -CheckOnly
```
